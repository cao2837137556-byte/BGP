- `HANDOFF.md`：项目交接与当前状态总览
- `EXPERIMENT_MAINLINE.md`：实验主线总表

维护规则：

- 不再继续新增“按日期拆开的 handoff 文件”作为默认入口。

- 旧路径下的文档先保留，作为历史归档，不再作为默认阅读入口。

1. `project_docs/HANDOFF.md`
